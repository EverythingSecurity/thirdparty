# Times Table Adventure

A single-file, no-dependency browser game that helps kids practice multiplication tables.

## How to play

Open `index.html` in any modern browser (no build step, no server required).

1. Pick one or more times tables (×1 through ×12).
2. Choose a difficulty (Relaxed / Normal / Speedy — controls the per-question timer, or no timer at all).
3. Choose how many questions to answer (10 / 15 / 20).
4. Answer multiple-choice questions, build a streak, and earn a star rating at the end.

## Notes

- Pure HTML/CSS/JS, no external assets or network calls — safe to open offline.
- Unrelated to the rest of this repository's application code; kept in its own `games/` folder as a standalone kids' learning game.
